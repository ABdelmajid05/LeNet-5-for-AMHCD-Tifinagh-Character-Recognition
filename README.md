# LeNet-5 for AMHCD Tifinagh Character Recognition

## Project Overview

This project implements and evaluates a LeNet-5 convolutional neural network (CNN) for handwritten Tifinagh character recognition using the AMHCD dataset.

The main objective is to compare two optimization algorithms, **Stochastic Gradient Descent (SGD)** and **Adam**, and evaluate their impact on the training process and classification performance.

## Objectives

- Implement the LeNet-5 architecture using TensorFlow and Keras.
- Preprocess RGB images and prepare the dataset for training.
- Train and evaluate the model using training, validation, and test sets.
- Compare SGD and Adam under the same experimental conditions.
- Analyze accuracy, loss, precision, recall, and F1-score.
- Visualize learning curves, confusion matrices, and convolutional feature maps.

## Dataset

The project uses the AMHCD handwritten Tifinagh character dataset.

- Number of images: 25,740
- Number of classes: 33
- Images per class: 780
- Input image size: 32 × 32 pixels
- Input channels: 3 (RGB)

The dataset is not included in this repository. Please obtain the dataset from its authorized source and configure the dataset paths in the notebook before running it.

## Model Architecture

The LeNet-5 model follows these main stages:

1. **Input:** 32 × 32 × 3 RGB image
2. **Convolutional layer C1:** 6 filters of size 5 × 5
3. **Average pooling layer S2:** 2 × 2
4. **Convolutional layer C3:** 16 filters of size 5 × 5
5. **Average pooling layer S4:** 2 × 2
6. **Fully connected layer C5:** 120 neurons
7. **Fully connected layer F6:** 84 neurons
8. **Output layer:** 33 classes

The model is adapted to accept RGB images while preserving the main structure of LeNet-5.

## Optimizers Compared

### SGD
Stochastic Gradient Descent updates the model parameters using the gradient of the loss function. Momentum is used to improve optimization.

- Learning rate: 0.01
- Momentum: 0.9

### Adam
Adam adapts the learning rate for individual parameters using estimates of first and second moments of the gradients.

- Learning rate: 0.001

Both optimizers use the same model architecture and data splits to make the comparison fair.

## Experimental Evaluation

The notebook evaluates the models using:

- Test accuracy
- Test loss
- Macro precision
- Macro recall
- Macro F1-score
- Training time
- Validation accuracy and loss curves

The generated results can be used to determine which optimizer performs better for this classification task.
